# MCP tool names to scripts/check-tool-names.sh but are not tools. One name per
# line; the text after # says what it is. Add a name here only when it is
# really not a tool (an argument, a refusal code, a field, an app-code
# function); a misspelled or retired tool name is fixed in the skill instead.
# An allowlisted name passes everywhere, called or not, so a retired tool's
# name never belongs here.
